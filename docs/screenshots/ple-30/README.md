# PLE-30 화면 검증

2026년 11월 9일, PR #26의 `cad5bb6` APK를 실행 중인 Pleos 에뮬레이터(API 34, 2560×1440, 사용자 10)에 설치해 확인했습니다. 차량 패널이 표시된 P단 상태에서 GPS를 80km/h로 재생했습니다. 실제 주행은 카카오 검색·OSRM·GuidanceSession을, 시연은 rain-commute 데이터를 사용했습니다.

## 음성 확인 방법

SDK의 `doSpeak(com.example.pleosproj)`와 TtsCallback의 시작·중단 로그 및 화면 버튼 상태를 확인했습니다. 아래 시각은 에뮬레이터 로그 기준입니다.

| 구분 | 시각 | 확인한 발화 |
| --- | --- | --- |
| 실제 브리핑 | 07:26:33.776 | 삼성역 2호선까지 7분, 경로에 위험 구간이 없습니다 |
| 실제 첫 회전 | 07:27:59.461 | 1킬로미터 앞에서 언주로 방면으로 좌회전입니다 |
| 실제 음성 재개 후 | 07:30:48.686 | 300미터 앞에서 영동대로 방면으로 우회전입니다 |
| 실제 도착 | 07:31:31.724 | 목적지에 도착했습니다. 안내를 마칩니다 |
| 시연 초기 브리핑 | 07:32:52.204 | 삼성역까지 18분, 통제 예정·강수 예보·물 고임 주의 |
| 시연 회전 | 07:33:23.497 | 1킬로미터 앞에서 언주로로 좌회전입니다 |
| 시연 위험 경고 | 07:34:26.617 | 1.1킬로미터 앞 선정릉역 부근 물 고임입니다. 주의해서 지나가 주세요 |

실제 주행에서 음성을 끈 뒤 출발점에서 약 3.3km를 지난 시점까지 마지막 발화가 07:27:59.461로 유지됐고, 다시 켠 뒤 발화가 재개됐습니다. 시연에서도 음성을 끈 뒤 59초 동안 새 doSpeak 요청이 없었습니다.

실제 통제 지점의 우회는 이번 주행 환경에 해당 알림이 없어 실행하지 못했습니다. 현재 알림의 hazardId를 acceptDetour에 전달하고 우회 성공·실패 이벤트를 표시하는 연결은 단위 테스트로 확인했습니다.
