# PLE-42 화면 확인

2026-11-09, 사람이 켜 둔 Pleos Connect API 34 에뮬레이터(2560×1440)에서 `adb exec-out screencap -p`로 캡처했습니다. 왼쪽 차량 패널과 오른쪽 앱 영역을 포함한 원본입니다.

| 파일 | 확인 내용 |
| --- | --- |
| `search.png` | 실제 검색 첫 화면. 교통 미반영 문구가 상시 보이지 않습니다. |
| `compare.png` | 실제 카카오모빌리티 후보의 세로 카드, 시간 차이, 통행료, 선택 강조, 실제 날씨입니다. 카드 폭은 앱 영역의 약 34%이고 숫자·단위 크기를 나눴습니다. |
| `other-routes.png` | 실제 안내 중 조회한 후보와 지금 길 대비 시간 차이, 새 길 시작·계속 가기입니다. |
| `guidance.png` | 전폭 제목 줄을 줄인 실제 안내입니다. 파란 회전 카드, 한 줄 도착 정보, 위험·교통 위주의 진행 막대, 실제 Vehicle 속도입니다. |
| `hazard.png` | 일시정지한 시연의 위험 카드와 같은 위험 지점 거리, 예시 시설·거리별 날씨입니다. |
| `north-up.png` | 같은 시연 위치에서 북쪽 고정·기울기 0°입니다. |
| `driver.png` | 같은 시연 위치에서 운전석 시점·기울기 55°입니다. |
| `night.png` | 같은 시연 위치에서 낮/밤 전환 후 지도·카드·조작 버튼의 어두운 테마입니다. |
| `reference/compare.png` | WeatherMap 예시 앱의 경로 비교 원본입니다. |
| `reference/guidance.png` | WeatherMap 예시 앱의 안내 원본입니다. |

실제 경로의 10km·20km 날씨와 시설 목록은 아직 연결부가 없어서 정보 없음으로 표시합니다. 시연의 시설과 거리별 날씨는 표시 예시임을 화면에 명시했습니다. 값과 화면비가 달라 예시 앱과 숫자는 일치하지 않습니다.

지도 확대·축소, 상세 지도, 이동 후 내 위치 복귀, 음성 전환도 직접 조작해 확인했습니다. 안내 중 비교의 계속 가기는 기존 안내를 유지했고, 다른 후보 시작은 실제 안내 경로를 바꿨습니다. 위치 재생 스크립트와 시연 재생은 확인 후 종료했습니다.
