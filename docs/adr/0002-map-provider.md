# 0002. 지도

- 상태: Proposed
- 날짜: 2026-10-31

## 맥락

앱은 안내 화면과 위험 지도를 직접 그리므로 지도를 띄울 방법이 필요하다.

Pleos Maps Platform 문서에 Map SDK for Android가 있지만, 공모전용 Pleos Maven 저장소에는 올라와 있지 않아서 받을 수 없다. 다른 Pleos 공모전 참가 앱이 MapLibre로 에뮬레이터에서 지도를 그린 사례가 있다.

## 결정

지도 엔진은 MapLibre Android를 쓰고, 배경 지도는 OpenStreetMap 데이터로 만든 공개 타일 서비스(OpenFreeMap 등)를 쓴다. OSM 공식 타일 서버는 이용 정책상 앱에서 쓰지 않는다. 지도 화면에는 OpenStreetMap 출처를 표시한다.

지도 코드는 `ui/map/`에 모아 두고, Pleos Map SDK를 쓸 수 있게 되면 이 부분만 바꾼다.

TMAP, 카카오맵, 네이버 지도 같은 상용 지도는 쓰지 않는다.

## 검토한 대안

Pleos Map SDK는 기본 내비와 같은 모양이고 Pleos SDK 활용으로도 좋지만, 지금은 받을 수 없다.

상용 지도는 한국 지도 품질이 좋다. 하지만 경로는 기본 내비 것을 쓰기 때문에 배경 지도 품질 말고는 얻는 게 없고, 키 발급과 사용 조건을 따로 챙겨야 한다. 차량용 안드로이드에서 동작하는지도 확인된 적이 없다.

## 결과

키나 과금 없이 바로 개발할 수 있다. MapLibre는 기본 내비가 쓰는 Mapbox와 뿌리가 같아서 비슷한 느낌의 지도를 만들 수 있다.

OSM은 큰 도로는 괜찮지만 지명이나 세부 도로는 상용 지도보다 부족할 수 있다. 스타일에서 한국어 이름을 먼저 보이게 한다. 터널, 지하차도, 하천 정보는 침수 취약 지점을 찾는 데에도 쓸 수 있다.

Pleos Map SDK가 공개되거나, 시연 화면에서 지도 품질이 부족하다고 판단되면 다시 정한다.
