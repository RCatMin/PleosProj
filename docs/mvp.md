# MVP: 1차 제출

현대자동차그룹 차량용 앱 개발 공모전 일반 부문에 낼 앱의 범위와 일정을 정리한 문서다. 결정의 이유는 `docs/adr/`에 따로 적는다. 할 일은 Linear(팀 Pleos, 프로젝트 "1차 제출")에서 관리한다.

## 무엇을 만드나

비, 눈, 침수, 결빙, 도로 통제 같은 위험을 미리 보여 주고 안전한 길로 가도록 돕는 Pleos Connect 앱이다. 이름은 아직 정하지 않았고 가칭은 SafeRoute다.

경로 계산과 회전 안내는 Pleos 기본 내비가 하고, 앱은 그 정보를 NaviHelper로 받아 와서 위험 정보와 함께 내비 화면처럼 보여 준다. 지도는 MapLibre로 그린다.

1차 제출의 목표는 에뮬레이터에서 "도심 폭우 퇴근길" 시나리오를 처음부터 끝까지 보여 주는 것이다. 위험 구간이 지도에 나오고, 안전한 경로가 기본 내비로 넘어가고, 위험 지점에 가까워지면 음성으로 경고하는 장면을 시연 영상과 APK로 낸다.

## 심사 기준별로 보여 줄 것

- 차량 특화성: 와이퍼, 외기온도, 안개등 상태로 예보를 보정한다. 차종에 따라 침수 기준을 다르게 둔다. 정차 중에는 출발 전 브리핑을, 주행 중에는 음성 안내만 한다.
- 창의성: 지하차도나 하천변 도로처럼 들어가 보기 전에는 알 수 없는 위험을, 그 구간을 지날 시각의 예보로 미리 알려 준다. 동승자가 위험 정보를 대신 확인할 수 있게 한다.
- 기술 활용성: NaviHelper, FusedLocation, Vehicle, TextToSpeech, SpeechToText를 핵심 기능에 쓴다.
- 사업성: 침수 취약 지역을 지나 출퇴근하는 운전자가 첫 대상이다. 평소에는 결빙, 안개, 통제 안내로 계속 쓰게 하고, 물류 차량과 보험 쪽으로 넓힐 수 있다.

## 1차 제출까지 할 것

- [ ] 에뮬레이터에서 앱 실행
- [ ] 목적지를 정하면 안내 화면에 다음 회전, 남은 거리, 도착 시각 표시
- [ ] 침수·결빙·통제 지점을 지도와 세로 진행 막대에 표시
- [ ] 시나리오에서 후보 경로를 위험도로 비교하고 가장 안전한 경로를 기본 선택
- [ ] 선택한 경로를 기본 내비로 넘기기
- [ ] 위험 지점에 가까워지면 음성 경고, 새 위험이 생기면 우회 제안
- [ ] 정차 중 시동을 켜면 출발 전 브리핑
- [ ] 와이퍼 단계와 차종을 위험도에 반영
- [ ] "도심 폭우 퇴근길" 시나리오 재생
- [ ] release APK 빌드

## 이번에 하지 않는 것

- 회전 안내 엔진을 직접 만드는 일 (기본 내비가 한다)
- TMAP 같은 상용 지도나 길찾기 서비스
- 실제 주행 중 지도 위 경로선 표시
- 차량 제어
- 서버, 차량 간 위험 정보 공유

## 에뮬레이터에서 알게 된 제약

- NaviHelper는 경로선 좌표를 주지 않는다.
- 에뮬레이터에서 위치를 바꿔도 기본 내비는 움직이지 않는다. 에뮬레이터가 보내는 GPS 문장의 체크섬이 틀려서 기본 내비가 버린다. FusedLocation은 정상적으로 따라온다.
- 에뮬레이터 기본 내비에는 배경 지도가 나오지 않는다.
- Pleos 콘솔에서 FusedLocation, TextToSpeech, SpeechToText, Vehicle Control은 아직 준비 중으로 나온다. 에뮬레이터에서는 Vehicle Control만 막혀 있다.
