# PLE-48 카드 배치와 파란색 UI

앱 이름은 ETA입니다. 일반·시연 화면 제목과 Android 앱 표시 이름에 같은 `app_name` 리소스를 사용합니다.

최신 글꼴은 Pleos 기본 Asta Sans입니다. 앱에 넣었던 Pretendard 덮어쓰기·글꼴 파일·해당 라이선스 복사본을 제거했습니다. 확인한 Pleos API 34의 `/product/etc/fonts_customization.xml`은 기본 `sans-serif`를 `AstaSansOTF-*.otf`에 연결합니다. 별도 글꼴을 묶지 않고 플랫폼 기본 글꼴을 사용하므로 다른 Android 기기에서는 그 기기의 기본 글꼴을 따릅니다.

브리핑의 도착 예정·예상 소요 값은 같은 스타일(38sp, SemiBold, 줄 높이 46sp)을 공유합니다. 겨울 19:03·33분과 폭우 18:28·18분의 화면 영역이 높이 46px·같은 세로 위치임을 확인했습니다. 빌드·설치를 통과했고 검색·비교·안내와 시연 이동·복귀도 확인했습니다. [최신 글꼴 캡처 5장](screenshots/ple-48-asta/README.md)에 정리했습니다.

추가된 시연 4배속·진행 막대 이동은 [PLE-50](ple-50-demo-seek.md)에 정리했습니다.

사용자가 제공한 2026-11-09 18:25:08 주행 카드, 18:26:25 비교 카드 기준으로 정리했습니다. PR #40에서 PLE-46의 실제 예보·시설 연결과 함께 검토합니다.

## 화면 구성

- 비교 화면은 왼쪽 목적지와 세로 후보 목록, 목록 아래 진행 버튼으로 배치합니다. 선택한 카드의 예보 막대 아래에는 출발·중간 두 지점·도착의 실제 통과 시각·거리·예보를 표시합니다. 근거는 전달된 값으로 표시합니다.
- 지도 위 후보 이름·‘선택’·‘제외’ 문구는 제거한 상태를 유지합니다. 선과 카드 강조로 선택을 구분합니다. 출발·도착 표시는 유지하고, 위험 원·이름표는 경로 구간선과 범례로 바꿨습니다.
- 주행은 파란 회전 카드 안에 다음 회전과 도착 시각·남은 거리·소요 시간·통행료를 표시합니다. 그 아래 위험 알림·시설 목록, 왼쪽 하단 가로 날씨 3개와 조작 영역을 배치합니다. 빈 시설 목록은 숨기며 정보가 많으면 위쪽 목록을 세로로 움직일 수 있습니다.
- 오른쪽 전용 진행 막대는 유지하며 현재 회전·위험·혼잡 정보와 내 위치를 표시합니다. 하단 음성 버튼은 실제 음성 안내 켜기·끄기입니다.
- 브리핑의 목적지·도착·소요 시간, 위험 요약과 전체 날씨 목록은 유지합니다. 사진의 시험용 시설이나 거리별 날씨를 복제하지 않습니다.

## 색상

기준 파란색은 `#2A70FF`입니다. 회전 카드·선택·예보 막대·경로선·내 위치(반투명 외곽 포함)·진행 막대·지도 버튼 배지·권한 상태에 적용했습니다. 다른 후보는 연한 파란색, 선택 배경은 `#EEF4FF`, 야간 강조는 `#ABC9FF`입니다.

Compose의 보조 강조·선택 배경·팝업 표면색과 Android 주야간 테마의 기본 보라색도 교체했습니다. 대설의 기존 보라색은 요청대로 파란색으로 바꾸고 위험 기호·이름을 함께 표시합니다. 나머지 위험/혼잡 종류의 표시 의미는 유지합니다. 사용자 요청을 `AGENTS.md` 화면 규칙에도 반영했습니다.

`ui/state/`, 경로·예보·위험 계산, SDK·권한·의존성은 변경하지 않았습니다. 기존 위치 보간·지도 프레임 제한과 브리핑 애니메이션도 유지합니다.

## 확인

설치·최초 검증은 2026-11-09, 최종 화면 검증은 2026-11-10에 진행했습니다.

이전 코드 커밋 `6266e33`에서 `assembleDebug`, `testDebugUnitTest` 158개(실패·오류 0), `installDebug`를 통과했습니다. 실행 중인 Pleos API 34 에뮬레이터에 설치했으며 전원·해상도는 변경하지 않았습니다.

폭우 시연의 경고 확인·닫기·주야간 전환과 실제 경로의 시설을 최종 배치에서 확인했습니다. 약 18초간 위치를 재생한 후 성남IC 2.8→2.5km, 성남졸음쉼터 3.7→3.3km로 갱신됐습니다. 실제 위치 재생과 안내를 종료했습니다.

폭우 시연에서 왼쪽 세로 후보, 통제 후보 선택 차단, 파란 회전 카드와 다음 회전·카드 안 도착 정보, 가로 날씨와 정보 없음 처리, 음성 안내 전환·4배 재생을 확인했습니다. 실제 양주역 경로의 왼쪽 카드에서도 기상청 근거·예보 4개·통과 시각이 표시됩니다.

[최종 캡처](screenshots/ple-48-blue/README.md)는 `adb exec-out screencap -p` 원본입니다. PLE-46의 이전 검증 캡처는 실제 데이터 연결의 증거이며, 현재 배치는 이 캡처를 기준으로 봅니다.

겨울 요약의 ‘강한 비’는 기존 개발 이슈 [PLE-47](https://linear.app/scsblog/issue/PLE-47) 범위입니다. null 지점 예보는 코드에서 처리하지만 실제 응답에 해당 사례가 없어 실행 캡처가 없습니다. 브리핑의 상세 위험 타임라인과 미연결 음성 명령은 현재 계약·연결부에 없어 추가하지 않았습니다.

## 지도 위험 구간선·범례와 모드 버튼 추가 수정

지도 위 위험 원과 그 아래 이름표를 없애고, 경로를 따라가는 색 구간선으로 표시합니다. 우측 하단 범례에는 현재 경로에 그린 위험만 표시하며 같은 색을 쓰는 침수·호우 등은 한 줄로 묶습니다. 대설은 기본 경로보다 진한 파랑 `#1653B5`로 구분합니다.

안내의 `HAZARD` 진행 구간에 종류와 시작·끝 비율이 있으면 그 범위를 사용합니다. 지점만 전달된 비교 후보·안내 위험은 경로의 가장 가까운 위치 앞뒤 80m를 짧게 강조합니다. 이 길이는 위치 강조용이며 실제 위험 구역의 범위를 계산한 값이 아닙니다. 각 후보 경로에 좌표를 따로 투영하고, 후보별 위험 목록·유효한 경로 비율처럼 연결부가 이미 배정한 위험은 그대로 표시합니다. 경로에 배정되지 않은 지점만 경로 주변 150m 안에 있을 때 표시합니다. 강조선은 도로의 꺾이는 점을 따라갑니다.

위험 구간선은 경로·위험·전달 구간이 바뀔 때만 다시 만들며 기존 위치 보간과 프레임 제한을 유지합니다. 경로가 없거나 표시할 위험이 없어지면 선과 범례도 사라집니다. 해 아이콘은 8개 햇살과 빈 중심으로 내 위치 표식과 구분하고, 달 아이콘은 채운 초승달로 바꿨습니다. 버튼 아래에는 전환 대상인 ‘라이트’ 또는 ‘다크’를, 접근성에는 현재 모드와 전환 동작을 표시합니다.

추가 검증: 도로 굴곡·끝점·중복 좌표, 후보별 투영·잘못된 경로 비율 무시, 안내 범위 우선 사용, 범위 변경·비움, 경로 누락·잘못된 좌표 및 GeoJSON 선 출력에 대한 단위 테스트를 추가했습니다.

최종 추가 수정 빌드에서 `assembleDebug`, 단위 테스트 166개(실패·오류 0), `installDebug`를 통과했습니다. 에뮬레이터에서 폭우 비교의 후보 전환·주야간 왕복, 안내 경고·주야간, 실제 양주역 계획·안내와 위치 재생, 겨울 비교를 확인했습니다. 최신 화면은 같은 최종 캡처 목록에 갱신했습니다. 앱은 폭우 시연의 경로 비교 화면에 재생을 멈춘 상태로 뒀습니다.
