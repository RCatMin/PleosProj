# MVP — 1차 제출 (11/15)

> 이 문서는 범위와 일정의 기준이다. 결정의 이유는 `docs/adr/`에 있다.
> Linear: SCSBlog 워크스페이스 · 팀 `Pleos`(PLE) · 프로젝트 "1차 제출"

## 목표

현대자동차그룹 차량용 앱 개발 공모전(일반 부문) 1차 접수에 낼 결과물을 만든다.

**호우·침수·대설·결빙·도로 통제 위험을 미리 보여 주고, 안전한 경로로 가게 돕는 Pleos Connect 앱.** (가칭 SafeRoute, 패키지 `com.example.pleosproj`)

완료 기준: **Pleos 에뮬레이터에서 "도심 폭우 퇴근길" 시나리오를 재생하면, 앱이 위험 구간을 지도에 보여 주고, 안전한 경로를 기본 내비에 넘기고, 주행 중 위험 지점 앞에서 음성으로 경고·우회를 제안한다.** 이 장면을 시연 영상과 APK로 제출한다.

## MVP 성공 기준

- [ ] Pleos 에뮬레이터에서 앱이 실행된다
- [ ] 목적지를 정하면(기본 내비 검색·최근 목적지) 안내 화면에 다음 회전·남은 거리·도착 시각이 나온다
- [ ] 침수·결빙·통제 지점이 지도에 표시되고, 세로 진행 막대에 위험 구간이 표시된다
- [ ] 시나리오 모드에서 후보 경로를 위험도와 함께 비교하고, 가장 안전한 경로가 기본 선택된다
- [ ] 선택한 경로를 NaviHelper로 기본 내비에 넘긴다
- [ ] 위험 지점 반경에 들어서면 음성으로 경고하고, 새 위험이 생기면 우회를 제안한다
- [ ] 정차 중 시동을 켜면 출발 전 브리핑을 들려준다
- [ ] 와이퍼 단계와 차종이 위험도 계산에 반영된다
- [ ] "도심 폭우 퇴근길" 시나리오를 처음부터 끝까지 재생할 수 있다
- [ ] release APK를 만들 수 있다

## 하지 않는 것 (1차 제출까지)

- 자체 경로 계산·회전 안내 엔진 (기본 내비가 맡음, ADR 0004)
- TMAP 등 상용 지도·길찾기 서비스 (ADR 0002)
- 실제 주행 모드에서의 경로선 표시 (NaviHelper가 좌표를 주지 않음, ADR 0005)
- 차량 제어 (Vehicle Control은 막혀 있고, 우리는 읽기만 함)
- 서버, 차량 간 위험 공유
- 실시간 데이터 완전 연동 (시연은 시나리오 데이터로도 충분)

## 알려진 제약 (10/30 에뮬레이터 확인, PLE-12)

- NaviHelper는 **경로선 좌표를 주지 않는다.** 경로는 비율로만 표현된다.
- 에뮬레이터 GNSS가 NMEA 체크섬을 `*47`로 고정해 보내서 **기본 내비 위치가 움직이지 않는다.** FusedLocation은 `adb emu geo fix`로 움직인다.
- 에뮬레이터 기본 내비에 **배경 지도가 나오지 않는다** (`No HMG Account found`).
- Pleos 콘솔에서 FusedLocation·TextToSpeech·SpeechToText·Vehicle Control은 **'준비 중'**이다. 에뮬레이터에서는 Vehicle Control만 막혀 있다.
- 공모전 문의 메일은 받지 않는다 (10/31). 위 문제는 답 없이 진행한다.
