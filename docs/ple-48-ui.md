# PLE-48 카드 배치와 파란색 UI

사용자가 제공한 2026-11-09 18:25:08 주행 카드, 18:26:25 비교 카드 기준으로 정리했습니다. PR #40에서 PLE-46의 실제 예보·시설 연결과 함께 검토합니다.

## 화면 구성

- 비교 화면은 왼쪽 목적지와 세로 후보 목록, 목록 아래 진행 버튼으로 배치합니다. 선택한 카드의 예보 막대 아래에는 출발·중간 두 지점·도착의 실제 통과 시각·거리·예보를 표시합니다. 근거는 전달된 값으로 표시합니다.
- 지도 위 후보 이름·‘선택’·‘제외’ 문구는 제거한 상태를 유지합니다. 선과 카드 강조로 선택을 구분하며, 위험 지점과 출발·도착은 그대로 표시합니다.
- 주행은 파란 회전 카드 안에 다음 회전과 도착 시각·남은 거리·소요 시간·통행료를 표시합니다. 그 아래 위험 알림·시설 목록, 왼쪽 하단 가로 날씨 3개와 조작 영역을 배치합니다. 빈 시설 목록은 숨기며 정보가 많으면 위쪽 목록을 세로로 움직일 수 있습니다.
- 오른쪽 전용 진행 막대는 유지하며 현재 회전·위험·혼잡 정보와 내 위치를 표시합니다. 하단 음성 버튼은 실제 음성 안내 켜기·끄기입니다.
- 브리핑의 목적지·도착·소요 시간, 위험 요약과 전체 날씨 목록은 유지합니다. 사진의 시험용 시설이나 거리별 날씨를 복제하지 않습니다.

## 색상

기준 파란색은 `#2A70FF`입니다. 회전 카드·선택·예보 막대·경로선·내 위치(반투명 외곽 포함)·진행 막대·지도 버튼 배지·권한 상태에 적용했습니다. 다른 후보는 연한 파란색, 선택 배경은 `#EEF4FF`, 야간 강조는 `#ABC9FF`입니다.

Compose의 보조 강조·선택 배경·팝업 표면색과 Android 주야간 테마의 기본 보라색도 교체했습니다. 대설의 기존 보라색은 요청대로 파란색으로 바꾸고 위험 기호·이름을 함께 표시합니다. 나머지 위험/혼잡 종류의 표시 의미는 유지합니다. 사용자 요청을 `AGENTS.md` 화면 규칙에도 반영했습니다.

`ui/state/`, 경로·예보·위험 계산, SDK·권한·의존성은 변경하지 않았습니다. 기존 위치 보간·지도 프레임 제한과 브리핑 애니메이션도 유지합니다.
