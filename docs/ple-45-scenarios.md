# PLE-45 시연 시나리오 선택

## 동작

첫 화면의 `시연 모드`에서 시나리오 목록을 열고 제목·설명을 보고 고릅니다. 목록은 `ScenarioPlayer.list(context)`에서 읽고, 고른 id를 `ScenarioPlayer.load(context, id)`에 전달합니다. 화면에서 시나리오 id나 제목 목록을 고정하지 않습니다.

선택 후에는 기존 브리핑 → 경로 비교 → 안내 → 종료 흐름을 사용합니다. 브리핑·안내의 `다른 시연`, 종료 화면의 `다른 시연 선택`, 브리핑에서 뒤로 가기로 목록에 돌아옵니다. `첫 화면`은 실제 목적지 검색 화면으로 돌아갑니다.

시나리오를 바꾸면 이전 재생과 음성을 먼저 멈추고 세션을 정리한 뒤, 새 세션을 생성합니다. 선택했던 경로·알림 확인·재생 시간은 새 시나리오로 이어지지 않습니다. 지도 추적도 출발 위치로 돌아옵니다. 종료 화면에는 선택한 시나리오의 제목을 표시합니다.

목록 로딩·실패·빈 목록과 선택한 시나리오 로딩 실패를 구분하며 다시 읽기 또는 목록 복귀가 가능합니다. 시나리오 내용, 엔진, `ui/state/`, 권한·의존성은 수정하지 않습니다.

## 확인 결과 (2026-11-09)

`assembleDebug`, `testDebugUnitTest` 155개, `installDebug`가 통과했습니다. 설치한 빌드는 코드 커밋 `91a857b`입니다.

- 시연 목록에 폭우·겨울의 제목과 설명이 표시되고 각각 선택됩니다.
- 폭우 선택 → 삼성역 브리핑 → 봉은사로 경로 비교 → 안내를 확인했습니다.
- 폭우 안내의 `다른 시연` → 겨울 선택 후 목적지가 신당역으로, 재생 시간이 00:00 / 33:00으로 바뀌는 것을 확인했습니다.
- 겨울 브리핑 → 한남대교 추천 경로 비교 → 안내에서 눈·영하 날씨와 결빙 경고를 확인했습니다.
- Pleos TTS 로그에서 15:09:21에 결빙 주의 발화 요청을 확인했습니다. 이 기록은 발화 요청 확인이며 실제 소리를 들었다는 의미는 아닙니다.
- 자동 관찰에서는 겨울 재생 24분대까지 확인했습니다. 이후 사용자가 직접 검증했고 “문제 없네”라고 확인했습니다. 자동 관찰로 33분 전체 재생·도착·종료 후 재시작까지 검증한 것으로 기록하지 않습니다.
- 사용자 검증으로 인계한 뒤 에뮬레이터를 추가로 조작하지 않았습니다.

캡처는 [스크린샷 목록](screenshots/ple-45/README.md)에 정리했습니다. `adb exec-out screencap -p` 원본입니다.

## 별도 개발 이슈

겨울 경로 요약에 ‘경로 전체 강한 비’가 표시되는 기존 연결부 문제는 [PLE-47](https://linear.app/scsblog/issue/PLE-47)로 분리했습니다. 시나리오나 개발 영역을 수정하지 않았습니다. 시설·거리별 날씨의 예시 표시는 기존대로 유지하며, 실제 값 연결은 PLE-46 범위입니다.
