# PLE-50 시연 4배속과 장면 이동

시연 영상 촬영을 위해 UI 재생 연결부를 4배속으로 고정했습니다. 1·2·4배 선택 버튼을 제거하고 시연 제목 옆에 고정 ‘4배속’ 안내를 표시합니다. 시나리오를 새로 선택하거나 처음부터 다시 재생해도 같은 속도입니다.

## 사용법

- 안내 오른쪽 진행 막대의 빈 곳을 누르면 해당 진행률로 즉시 이동합니다. 위쪽은 목적지, 아래쪽은 출발입니다. 지나간 지점으로도 이동할 수 있습니다.
- 회전·위험·혼잡 항목을 누르면 해당 지점 약 200m 전으로 이동합니다. 위험 경고나 회전을 촬영할 여유를 주는 화면상의 이동 위치이며 위험 계산을 바꾸지 않습니다.
- 재생 중 이동하면 재생을 이어가고, 일시정지 중 이동하면 그 장면에서 멈춥니다. 항목 클릭으로 멈춘 장면을 준비한 뒤 ‘재생’을 눌러 촬영할 수 있습니다.
- 이동할 때 이전 경고 확인과 음성 판단 이력을 초기화합니다. 뒤로 이동해 같은 장면을 다시 재생할 수 있습니다.
- 막대 맨 위로 이동하면 도착 화면으로 끝나고, ‘처음부터 다시 재생’으로 돌아올 수 있습니다. ‘처음으로’는 출발로 이동한 뒤 정지합니다.
- 실제 주행에서는 클릭 이동과 ‘눌러서 이동’ 안내를 제공하지 않습니다.
- 안내 중 ‘다른 길 보기’로 들어갔다면 ‘안내 시작’ 위의 ‘이전으로 돌아가기’로 기존 안내에 복귀합니다. 시연 위치·경고 확인 상태를 유지하며 재생 중이었다면 이어서 재생하고 정지 중이었다면 정지를 유지합니다. 기기 뒤로 가기도 같습니다. ‘안내 시작’은 안내 문구대로 처음부터 다시 시작하는 별도 동작입니다.
- 경로 비교는 안내에서 쓰던 시점과 별개로 기울기 0도·북쪽 위의 평면으로 고정합니다. 비교 중 시점 선택은 숨기며 확대·이동·전체 경로·지도 종류·주야간 조작에도 각도를 유지합니다. 안내로 돌아오면 원래 주행 시점을 다시 사용합니다.

## 구현 범위

기존 `ScenarioPlayer.seek`를 `ui/demo`에서 호출합니다. 진행률과 시나리오 시간의 대응은 기존 재생기의 일정 속도 모델을 사용합니다. 위치·지도·다음 회전·남은 거리·날씨·경고는 이동한 시점의 안내 상태로 함께 바뀝니다. 새 위치는 기존 프레임 루프에도 즉시 적용됩니다.

이동 전 재생기를 멈추고 새 재생기로 교체해 이전 콜백을 무시합니다. 화면에 보이는 음성 선택은 유지하면서 이전 발화를 종료하고 경고 이력을 비웁니다. `scenario/`, `routing/`, `risk/`, `ui/state/`, 의존성·권한은 수정하지 않았습니다.

## 검증

`assembleDebug`, 단위 테스트 170개(실패·오류 0), `installDebug`를 통과했습니다. 기존 배속 전환 테스트는 4배속 고정·앞뒤 이동·정지 유지·이전 콜백 무시 검증으로 바꿨고, 범위 밖·유효하지 않은 시각·도착 후 되감기·막대 위아래 방향·200m 전 이동을 확인했습니다. 음성 컨트롤러의 이력 초기화·음소거 유지 테스트도 통과했습니다.

Pleos 에뮬레이터의 전원·해상도는 변경하지 않았습니다. 캡처는 [PLE-50 검증 화면](screenshots/ple-50/README.md)에 정리합니다. PLE-48의 이전 카드·색상 캡처에 있는 배속 선택은 이번 수정 전의 기록입니다.
