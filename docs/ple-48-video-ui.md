# PLE-48 영상 기준 화면 정리

2026-11-09에 사용자가 제공한 43.5초 프로토타입 영상의 경로 비교·브리핑·주행 정보 배치를 기준으로 정리했습니다. PLE-46의 실제 예보·시설 연결과 같은 PR #40에서 검토합니다.

## 반영한 배치

- 경로 비교: 지도 위 목적지와 위험 종류별 개수, 지도 아래 가로 후보 카드, 하단 선택 요약과 진행 버튼입니다. 지도 위 후보 이름과 ‘선택’·‘제외’ 문구를 그리던 source/layer를 제거했습니다. 지도에는 경로선 강조, 위험 지점, 출발·도착만 남습니다.
- 선택한 카드에 지점별 통과 시각·거리·예보와 근거를 표시합니다. 예보 4개가 한 번에 보이도록 높이와 글줄 간격을 조정했습니다. 후보가 3개 이상이면 좌우로 움직이며, 통제로 제외된 후보는 선택할 수 없습니다.
- 브리핑: 목적지·도착·소요 시간의 크기를 정리하고, 왼쪽 위험 요약과 오른쪽 날씨, 하단 경로 비교·안내 시작 버튼을 유지했습니다. 전달받은 실제 날씨 4장을 모두 표시합니다.
- 주행: 흰 회전 안내 카드와 왼쪽 날씨·시설, 왼쪽 아래 위험 알림, 오른쪽 전용 진행 막대, 하단 ETA·목적지·거리·통행료·조작 영역입니다. 진행 막대는 다음 회전과 위험/교통 정보를 표시하며 내 위치 이름표도 진행 비율을 따라 움직입니다.
- 날씨 아이콘은 영상처럼 단순한 윤곽으로 정리했습니다. 브리핑의 기존 아이콘/등장 애니메이션은 유지하고, 주행 지도 프레임 제한과 위치 보간도 유지했습니다.

영상의 개발 도구, 고정 시험 데이터와 미연결 음성 명령 버튼은 추가하지 않았습니다. 음성 버튼은 기존 음성 안내 켜기·끄기로 동작합니다. 브리핑에 위험별 거리·통과 시각을 그릴 자료가 없어 영상의 상세 위험 타임라인은 복제하지 않았습니다. `ui/state/`, 개발 영역, 의존성·권한은 변경하지 않았습니다.

## 확인

- 코드 커밋 `077e236`에서 `assembleDebug`, `testDebugUnitTest` 158개(실패·오류 0), `installDebug`를 통과했습니다.
- 실제 성남시청 → 양주역 경로에서 검색/최근 목적지 → 비교 → 브리핑 → 안내 → 다른 경로 → 지금 길로 계속 안내 → 종료를 확인했습니다. 예보 4개와 IC·쉼터·TG 시설, 거리별 날씨가 새 배치에 표시됩니다.
- `scripts/replay_route.py --speed-kmh 80 --user 10`을 약 18초 재생한 후 종료했습니다. 성남IC 2.8km → 2.5km, 쉼터 3.7km → 3.3km 등 거리와 회전 안내가 갱신됐습니다. 기존 엔진의 재탐색 결과도 화면에 반영됐습니다.
- 겨울 시연에서 후보 선택·선 강조, 눈·영하 표시, 누락된 거리별 예보·빈 시설 목록, 4배 재생·음성 전환·야간 화면을 확인했습니다. 폭우 시연에서는 가로 스크롤과 통제 후보의 선택 차단을 확인했습니다.

[최종 화면 캡처](screenshots/ple-48/README.md)는 `adb exec-out screencap -p` 원본입니다. 이전 PLE-46 캡처는 데이터 연결 검증 당시의 화면이며, 현재 배치는 PLE-48 캡처를 기준으로 봅니다.

겨울 위험 요약의 ‘강한 비’ 문구는 기존 개발 이슈 [PLE-47](https://linear.app/scsblog/issue/PLE-47) 범위입니다. 예보 지점의 null 처리는 구현돼 있으나 실제 API 결과에서 null인 지점이 없어 해당 상태의 실행 캡처는 없습니다.
