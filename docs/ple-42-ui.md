# PLE-42 예시 앱 화면 맞추기

## 구성

WeatherMap 내비 예시 앱의 정보 배치를 Pleos 앱 영역에 맞췄습니다.

- 경로 비교: 전체 지도 위 왼쪽 세로 카드, 실제 경로 이름·큰 예상 시간·차이·거리·통행료·위험 요약, 선택 카드 확장, 아래 안내 시작 버튼입니다. 출발 전 브리핑 흐름은 유지합니다.
- 안내: 파란 회전 카드와 다음 회전, 도착 시각·남은 시간·거리·통행료, 위험 카드, 시설 목록, 거리별 날씨, 하단 동작, 오른쪽 진행 막대와 차량 속도입니다.
- 안내 중 비교: 현재 안내를 유지하며 후보를 다시 받습니다. 시간 차이는 조회 완료 시점의 현재 길 남은 시간과 비교합니다. 새 길 시작 또는 지금 길 계속 가기를 선택합니다. 경로 선택은 정차 중에만 가능합니다.
- 지도: 확대·축소, 위에서 보기(기울기 30°), 북쪽이 위(평면·북쪽 고정), 운전석에서 보기(기울기 55°), 전체 경로, 내 위치 추적, 기본·상세 지도, 음성, 낮·밤 전환입니다. MapLibre와 OpenFreeMap을 그대로 씁니다.
- 글꼴: [Pretendard v1.3.9 공식 릴리스](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)의 가변 TTF입니다. 원본 라이선스를 `app/src/main/assets/licenses/pretendard.txt`에 포함했습니다. Gradle 의존성은 추가하지 않았습니다.

## 실제 데이터와 아직 없는 값

카카오모빌리티 경로의 시간·통행료·경로 이름과 위험 요약은 연결부의 값을 표시합니다. 상시 표시하던 “예상 시간에는 실시간 교통이 반영되지 않습니다” 문구는 제거했습니다. OSRM 대체 계산 사유가 있을 때만 교통 미반영을 알립니다.

현재 연결부에는 예상 정확도, 거리별 예보 통과 시각, 10km·20km 앞 날씨, IC·휴게소 전체 목록이 없습니다. 정확도는 미제공, 실제 주행의 해당 날씨는 `— / 정보 없음`으로 표시합니다. 실제 회전 안내에 고속도로 진입·진출·요금소가 있으면 시설 카드에 재사용합니다. 시연에서만 시설과 거리별 날씨를 `표시 예시`로 구분해 보여 줍니다. 실제 예보의 지금·목적지 값을 10km·20km 앞의 관측값으로 바꾸지 않습니다.

나머지 연결부는 [PLE-43](https://linear.app/scsblog/issue/PLE-43)으로 요청했습니다. 음성으로 경로 선택은 PLE-41 연결 전이라 준비 중으로 표시합니다. `ui/state/`, 개발 영역, Manifest, Gradle 설정은 변경하지 않았습니다.

재탐색이나 우회 후에는 새 통행료를 받는 API가 없으므로 이전 길의 요금을 남기지 않고 정보 없음으로 바꿉니다.

## 확인

빌드와 단위 테스트에 더해, 실행 중인 Pleos 에뮬레이터에 설치한 뒤 다음을 확인합니다. 에뮬레이터는 사람이 켜고 끕니다.

1. 실제 목적지 선택 → 교통 반영 경로 비교 → 브리핑 → 안내.
2. 다른 길 보기 → 시간 차이 → 지금 길 계속 가기, 다시 다른 길 보기 → 후보 선택 → 이 길로 안내 시작.
3. 지도 시점 3종, 확대·축소, 지도 이동 후 내 위치로, 기본·상세 지도, 낮·밤, 음성 켜기·끄기.
4. 시연의 위험 카드·예시 시설·거리별 날씨와 안내 종료 확인.
5. `adb exec-out screencap -p`로 캡처하고 예시 앱 원본 캡처와 PR에서 나란히 비교.

예시 원본 캡처는 `docs/screenshots/ple-42/reference/`에 보관했습니다. 휴대폰 알림, 시각 비교 같은 시연 전용 화면은 구현하지 않았습니다.
