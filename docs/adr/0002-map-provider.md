# 0002. 지도: MapLibre + OpenStreetMap 기반 공개 지도

- 상태: Proposed
- 날짜: 2026-10-31

## 맥락

앱은 내비처럼 보이는 안내 화면과 위험 지도를 직접 그린다 (ADR 0004). 앱 안에 지도를 띄울 수단이 필요하다.

- Pleos Maps Platform 문서에 Map SDK for Android가 있지만, **공모전용 Pleos Maven 저장소에는 없다** (10/29 확인). 공모전 문의 메일은 받지 않아서(10/31) 사용 가능 여부를 확인할 수 없다.
- 처음 기획에서 TMAP을 넣었지만 검토 없이 들어간 것이라 뺐다 (10/29).
- 다른 Pleos 공모전 참가 앱(대동차지도)이 MapLibre로 Pleos 에뮬레이터에서 지도를 그린 사례가 있다.

## 결정

- 지도 엔진은 **MapLibre Android**를 쓴다.
- 배경 지도 데이터는 **OpenStreetMap 기반 공개 타일 서비스(OpenFreeMap 등)**를 쓴다. OSM 공식 타일 서버(tile.openstreetmap.org)는 이용 정책상 앱에서 쓰지 않는다.
- 지도 화면에 `© OpenStreetMap contributors` 출처를 표시한다.
- 지도 코드는 `ui/map/` 한 곳에 모은다. Pleos Map SDK를 쓸 수 있게 되면 이곳만 바꾼다.
- TMAP·카카오맵·네이버 지도 등 상용 지도는 쓰지 않는다. 바꾸려면 새 ADR로 정한다.

## 검토한 대안

- Pleos Map SDK — Pleos SDK 활용 점수와 기본 내비와 같은 모양이라는 장점이 크지만, 받을 방법이 없다.
- TMAP·카카오맵·네이버 지도 — 한국 지도 품질은 좋지만 키 발급·사용 조건 확인이 필요하고, Pleos(차량용 안드로이드 arm64)에서 동작하는지 확인된 사례가 없다. 경로는 어차피 기본 내비 것을 쓰므로(ADR 0004) 배경 지도 품질 차이만 남는다.
- MapLibre Navigation(길 안내 확장) — 경로 계산 서버가 따로 필요하고 기본 내비 역할과 겹친다.

## 결과

- 키 발급·과금 없이 바로 개발할 수 있다.
- MapLibre는 기본 내비가 쓰는 Mapbox와 같은 계열이라 비슷한 모양의 지도를 만들 수 있다.
- OSM은 한국에서 큰 도로는 좋지만 지명 표시·세부 도로·장소 정보가 상용 지도보다 부족할 수 있다. 스타일에서 한국어 이름을 우선하도록 설정한다.
- OSM의 터널·지하차도·하천 정보는 침수 취약 지점 찾기(ADR 0003)에도 쓸 수 있다.
- 다시 볼 조건: Pleos Map SDK가 공개되면, 또는 시연 화면에서 지도 품질이 부족하다고 판단되면.
